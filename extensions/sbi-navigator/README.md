# Insighta SBI Navigator（試験運用）

SBI証券で Insighta 用の取引履歴ファイルを保存する画面へ案内する Chrome 拡張機能です。

## 目的と配布方針

Insighta の `parse` コマンドは、利用者が SBI証券から保存した取引履歴ファイルを入力として使います。
この拡張機能は、その保存画面までの移動を分かりやすくするための開発用ツールです。

金融口座を扱うため、ログイン情報・Cookie・口座情報・取引履歴を読み取り、保存し、
外部へ送信することはありません。SBI証券サイトのDOMやダウンロード内容にもアクセスせず、
公式ポータルを開くことと保存手順の表示だけに責務を限定しています。

SBI証券の画面やURLの変更への追随と利用体験の検証を継続中のため、現時点では
Chrome Web Storeへ正規登録せず、デベロッパーモードで読み込む開発版として提供します。
機能範囲、必要権限、運用方針が安定した時点で、正式配布の可否を判断します。

## この拡張機能がすること

- SBI証券の公式ログインページを新しいタブで開く
- `insighta parse` に必要な HTML/CSV と、SBIポータル内での操作手順を表示する

## この拡張機能がしないこと

- ログイン情報、Cookie、口座情報、取引履歴を読む・保存する・外部へ送信する
- SBIサイトの画面を変更する
- ファイルを自動ダウンロードする

`manifest.json` に権限は指定していません。開くURLは `src/routes.js` の HTTPS SBI証券公式ドメインの allowlist で検証します。

## 開発版の読み込み

1. Chromeで `chrome://extensions` を開く。
2. 右上の **デベロッパーモード** を有効にする。
3. **パッケージ化されていない拡張機能を読み込む** を選び、この `extensions/sbi-navigator` ディレクトリを指定する。
4. 拡張機能アイコンを固定し、ポップアップから **SBI証券にログイン** を選ぶ。

保存したHTML/CSVは対象ワークスペースの `input/sbi/` に置きます。続いて次を実行してください。

```bash
insighta --work sbi-us-stocks parse
```

## URLと案内の更新

SBI証券の認証後URLはログイン状態やサイト更新に依存するため、固定URLを推測していません。画面名や手順は `src/routes.js` の `DOWNLOAD_ROUTES` で更新します。URLを追加する場合も、`isAllowedSbiUrl()` の allowlist とテストを必ず更新してください。

## テスト

Node.js 20以上で実行できます。外部パッケージのインストールは不要です。

```bash
npm test
```
